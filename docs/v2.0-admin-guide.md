# v2.0 Administrator Guide

Control 只有一个内置 Admin 角色。普通用户不需要角色即可登录，但创建后默认没有任何 SubAgent grant。

首次部署使用 `scripts/muye.sh init` 创建管理员。用户名和密码必须显式输入或由部署环境注入；服务重启不会重复执行初始化。登录后在 Web 的“授权”页面为用户选择已激活 Agent。授权变更即时生效，并会使撤销授权后的 citation 立即不可访问。

状态页面中的 Agent 状态含义如下：`DISCOVERED` 为合法但未部署，`STARTING` 为等待验证，`ACTIVE` 为可调用，`DEGRADED` 为健康阈值失败，`INACTIVE` 为已下线，`REJECTED` 为候选校验失败。管理员不应通过修改 Catalog 文件或环境变量绕过状态和授权流程。

管理员只能管理用户、grant、状态与拓扑；Web 没有源码、构建、发布或密钥管理入口。发布和回滚由受控 CLI 与部署身份执行。
