# v2.0 Release Checklist

- SDK、模板 manifest、JSON Schema 和基础镜像均固定为已审阅版本或 digest。
- `agent sync --check`、Python 测试、Web build、Compose config、SBOM 与许可证检查通过。
- 至少三组不同结构的知识输入均完成 schema/skill/profile 审批、生成、独立导入与模板契约测试。
- 在目标环境完成 Admin 初始化、登录、grant、Gateway SSE、citation 撤权、Agent deploy 和 rollback 验证。
- 备份恢复演练、token 轮换和公网端口扫描通过；仅 Gateway 开放预期端口。
- Alpha、RC 与正式版本分别记录不可变镜像 digest、Catalog checksum、SBOM 与验证证据。

将上述不可变证据写入可审阅 YAML 后，运行：

```bash
./scripts/muye.sh release verify release-evidence.yaml
```

证据必须包含当前模板源码 checksum、至少一份当前 JSON Schema checksum、每个部署服务的
`registry/repository@sha256:<manifest-digest>`、Catalog checksum 和 CI/目标环境验证记录引用。
校验器只验证冻结输入一致性，不会创建 tag、推送镜像或替代 E2E 证据。
