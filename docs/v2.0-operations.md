# v2.0 Operations Guide

完整环境是一个 Compose project。分别准备 `control_server/.env`、`muye-llm/.env`、
`muye-data/.env`、`agents/agent-main/.env` 与 `muye-gateway/.env`，填入各模块负责的
PostgreSQL、LLM、TLS 与服务 token 后执行：

```bash
./scripts/muye.sh init
./scripts/muye.sh doctor
./scripts/muye.sh up
./scripts/muye.sh status
./scripts/muye.sh smoke
```

`doctor` 校验配置与 Compose，`smoke` 只检查 Gateway 的公开健康端点和未认证请求拒绝。查看日志使用 `muye.sh logs [service]`，故障排查前先保留 Control、Gateway、Main 与目标 Agent 的日志；日志中不得包含 token、密码或原始知识正文。

PostgreSQL 是用户、会话和 grant 的持久化事实源。按组织的备份策略定期执行逻辑备份，并在隔离环境恢复后验证 `control_users`、`control_sessions` 与 `user_agent_grants`。恢复前停止写入；恢复后旋转所有服务 token 和管理员密码，并重新执行 `doctor` 与 `smoke`。

发布前必须重放 `agent sync --check`、受影响测试、Compose `config --quiet`、SBOM/许可证检查和目标环境的 deploy/rollback。不要挂载 Docker socket，不要公开 Control、Data、LLM 或任何生成 Agent 端口。
