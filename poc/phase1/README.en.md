# Phase 1 Vertical PoC

[中文说明](README.md)

This directory contains the Phase 1 vertical proof of concept and its local
Milvus development environment. It validates controlled Markdown parsing, stable
checksums, constrained Profiles, `AgentGenerationSpecV1` assembly, one-time ReAct
Agent-directory rendering, and refusal to overwrite developer-owned changes.

It is intended for development and validation rather than production deployment.
Consult the [Chinese README](README.md) for the complete startup sequence, sample
data, tests, and troubleshooting guidance.
